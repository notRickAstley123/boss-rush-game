# boss-rush-game
this is my first time trying to make a game in c++!
well. this was supposed to be a boss rush game but as of currently it only has a single boss , but at least it works and you can actually kind of win i guess
this uses SFML for its base, using sfml graphics, sfml audio (not used yet in this current uhh build), sfml system, sfml window, iostream (for output and testing reasons), cstdlib, cmath, vector, and algorithm
to run this, you just need to download all the files from the demo link (itch.io)
demo link: https://valencey.itch.io/a-boss-rush-game-stuff
also WASD is for movement and T is for your melee attack ! 
G is for your ranged attack, Q is supposed to be for a dash but i havent made one yet </3
